# 😊 きもちボード

特別支援学校・支援学級向けの、「がんばったこと（教科・活動）」と「きもち」を選ぶと、大きな画面と音声で伝えてくれる Web アプリです。

## 2つの モード（⚙️ → つかいかた）
- **ふりかえり**：「なにを した？」→「どんな きもち？」で 文に して 読み上げる（いままで どおり）
- **いま つたえる**：「いや・てつだって・やすみたい・もういっかい・トイレ」などを 1まいで 大きく つたえる。**2まいから はじめて 3・4・6・9まいへ** ふやせます（「🎯 カードを えらぶ」の ③で えらんだ じゅん）

## 2026年10月に ふえた こと
- 🎤 **先生の こえ**：どの カードにも 録音でき、読み上げの かわりに その こえが ながれます（この端末に 保存）
- ✨ **スキャン（1スイッチ）**：カードが じゅんに 光り、画面の どこか・スペース／エンター（Bluetooth スイッチ）で えらぶ。はやさは 4だんかい
- 📍 **場面**：画面 左上の 札を タップで「あさの かい・じゅぎょう・きゅうしょく…」と かわり、きろくに のこる（場面の リストは 先生が へんしゅう）
- 📊 **この端末の きろく**：えらんだ カード・場面・えらぶまでの 時間。カード別・場面別・「場面 × カード」の 集計と CSV。どの 場面で なにを 伝えたいかを 見つける 手がかりに

## 使い方（先生・保護者の方）

1. iPad の Safari でこのページの URL を開くだけ。ログイン・設定は不要です。
2. 共有ボタン（□↑）→「ホーム画面に追加」で、アプリのように全画面で使えます。
3. 先生用の設定（声の速さ・ボタンの列数など）は、右上の ⚙️ を **1.5秒ながおし**。

## 自分の学校用にボタンや写真を変えたい先生へ

Google スプレッドシートと連携すると、ボタンの中身・写真を自由に変えられます。
手順は [セットアップ手順.html](セットアップ手順.html) を見てください（`Code.gs` を使います）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `data.js` | 標準のボタン（教科・気持ち）と写真の指定 |
| `images/` | 標準の写真 |
| `Code.gs` | スプレッドシート連携用（Google Apps Script） |
| `セットアップ手順.html` | スプレッドシート連携の手順書 |
