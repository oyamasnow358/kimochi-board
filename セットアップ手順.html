😊 きもちボード　セットアップ手順

特別支援学校・支援学級向け「がんばったこと」と「きもち」を選んで、大きな画面と音声で伝えるアプリです。
プログラミングの知識がなくても、この手順どおりに進めれば 30分ほどで使えるようになります。

1. スプレッドシートを作る

  1. パソコンで Google ドライブ（drive.google.com）を開きます。
    ※ 学校から配布された Google アカウント、または個人アカウントでログインします（4. の注意も読んでください）。
  2. 左上の ＋ 新規 → Google スプレッドシート → 空白のスプレッドシート をクリック。
  3. 左上の「無題のスプレッドシート」をクリックして、名前を きもちボード に変えます。

シートの中身（列）は、3. でボタン1つで自動作成できるので、今は空のままでOKです。
自分で作る場合は、シート名を master にして、1行目に次の見出しを入れてください。

A: idB: categoryC: nameD: emojiE: imageUrlF: yomiG: colorH: show
s01教科こくご📖☑
s07教科じりつ🧩じりつかつどう☑
s08教科きゅうしょく🍚https://drive.google.com/file/d/…/view☑
f01気持ちたのしかった😄#FFD43B☑
f04気持ちむずかしかった🤔#74C0FC☑

列の意味は 7. で説明しています。

2. Apps Script（GAS）にコードを貼る

  1. スプレッドシートのメニューで 拡張機能 → Apps Script をクリック。新しいタブでエディタが開きます。
  2. 左上の「無題のプロジェクト」をクリックして、名前を きもちボード に変えます。
  3. コード.gs に貼る： 最初から開いている コード.gs の中身（function myFunction() {…}）を全部消して、Code.gs の中身を貼りつけます。
  4. index を作る： 左の「ファイル」の横の ＋ → HTML をクリックし、名前に index と入力して Enter（自動で index.html になります）。
    中身を全部消して、index.html の中身を貼りつけます。
  5. 上の 💾（プロジェクトを保存） をクリック（または Ctrl+S）。
⚠ 名前はまちがえずに HTML ファイルの名前は必ず index（小文字）にしてください。ちがう名前だとアプリ画面が表示されません。

3. サンプルデータを作る（初回だけ「許可」が必要）

  1. エディタ上部の関数えらび（「myFunction」などと表示されている所）で setupSampleSheet を選び、▷ 実行 をクリック。
  2. 「承認が必要です」と出たら 権限を確認 をクリックし、自分のアカウントを選びます。
  3. 「このアプリは Google で確認されていません」と出たら：
    左下の 詳細 → きもちボード（安全ではないページ）に移動 → 許可（または「すべて選択」にチェックして「続行」）。
  4. 「実行完了」と出たら、スプレッドシートのタブに戻ります。master シートにサンプルの教科・気持ちが入っていれば成功です。
ℹ「安全ではないページ」と出るのはなぜ？ 自分で作ったスクリプトは Google の審査を受けていないため、必ずこの表示が出ます。ここで許可するのは「自分が作ったスクリプトが、自分のスプレッドシートを読み書きすること」です。コードの中身は、このスプレッドシートの読み書き以外のことはしていません。
※ 学校のアカウントで「管理者によってブロックされています」と出る場合は、9. こまったときを見てください。

次回からは、スプレッドシートを開き直すとメニューに きもちボード が増え、「サンプルデータを作る」「データの読みこみテスト」がそこから実行できます。

4. ウェブアプリとして公開（デプロイ）する

  1. エディタ右上の デプロイ → 新しいデプロイ をクリック。
  2. 「種類の選択」の横の ⚙（歯車） → ウェブアプリ を選びます。
  3. 次のように設定します。
    項目設定
    説明きもちボード（なんでもOK）
    次のユーザーとして実行自分
    アクセスできるユーザー全員（下の注意を読んでください）
  4. デプロイ をクリック。（ここで再び許可を求められたら、3. と同じように許可します）
  5. 「ウェブアプリ」の URL（https://script.google.com/macros/s/…/exec）が表示されるので、コピー してメモ帳などに保存しておきます。これがアプリのURLです。
⚠「アクセスできるユーザー：全員」の注意点
  • 「全員」にすると、URLを知っている人ならだれでもログインなしで、ボタンの中身（教科名・気持ち・画像URL）を見ることができます。URLは推測できないほど長いので普通は見つかりませんが、URLを学校外に公開しないでください。
  • スプレッドシートの master シートには、児童の名前・顔写真などの個人情報を入れないでください。（シート全体が公開されるわけではありませんが、アプリで表示するデータは見られる可能性があります）
  • 「記録」機能をオンにした場合、記録されるのは「日時・教科・気持ち」だけです。記録シート（log）の中身はURLからは見えません。
  • 学校の Google Workspace では、管理者の設定で「全員」が選べないことがあります。その場合は「（学校名）内の全員」を選び、iPad の Safari でも学校のアカウントにログインしておけば、5. の方法Aで使えます。
💡 あとでコードを直したとき（URLを変えずに更新する方法） デプロイ → デプロイを管理 → 右上の ✏️（編集） → 「バージョン」を 新バージョン にして デプロイ。
※ 「新しいデプロイ」をすると URL が変わってしまうので注意。
※ スプレッドシートの中身を変えただけなら、デプロイし直す必要はありません。

5. iPad で開く・URLを設定する

方法A（おすすめ・かんたん）：GAS の URL をそのまま開く

  1. 4. でコピーした URL（…/exec）を iPad に送ります。
    例：Google Classroom の資料に貼る／自分あてにメールする／QRコードにして読み取る（Chrome の「共有 → QRコードを作成」などで作れます）。
  2. iPad の Safari でその URL を開くと、すぐにアプリが表示されます。URLの設定は不要です。
ℹ 方法Aの小さなちがい 個人の Google アカウントで作った場合、画面の上に「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」という灰色の帯が出ることがあります。使うことに問題はありません。気になる場合は方法Bを使います。

方法B：index.html を別の場所に置いて、URLを設定する

index.html を GitHub Pages などの Web サーバーに置く方法です。帯が出ず、ホーム画面から完全な全画面で使えます。

URL の設定方法は2通りあります：

  1. アプリの設定画面で入力（端末ごと）： アプリを開き、右上の ⚙️ を 1.5秒ながおし →「GAS ウェブアプリの URL」に貼りつけ →「🔄 データを読みこむ」。
    ※ アプリの URL の最後に ?settings=1 をつけて開くと、最初から設定画面が開きます。
  2. HTML に書きこむ（全端末で設定不要）： index.html をメモ帳で開き、次の行を探して '' の中に URL を貼ります。 
    const DEFAULT_API_URL = '';
      ↓
const DEFAULT_API_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
GitHub Pages に置く手順（参考）
  1. github.com で無料アカウントを作り、New repository で公開（Public）リポジトリを作ります。
  2. Add file → Upload files で index.html をアップロード → Commit changes。
  3. Settings → Pages → Branch を main にして Save。数分後に表示される URL がアプリの URL です。
※ 公開リポジトリは誰でも見られます。index.html に個人情報は含まれていませんが、GAS の URL を書きこんだ場合はその URL も見えることになります。

6. ホーム画面に追加して全画面で使う（iPad / Safari）

  1. Safari でアプリを開いた状態で、アドレスバー横の 共有（□に↑） をタップ。
  2. メニューを下にスクロールして ホーム画面に追加 をタップ。
    「Webアプリとして開く」というスイッチが出る場合は オン にします。
  3. 名前を「きもちボード」にして 追加。ホーム画面のアイコンから開くと、アドレスバーのない大きな画面で使えます。
💡 現場で使うコツ
  • アクセスガイド（ほかのアプリに移れなくする機能）：
    「設定」→「アクセシビリティ」→「アクセスガイド」をオン → アプリを開いてトップボタン（またはホームボタン）を3回すばやく押す →「開始」。終了も3回押してパスコードを入力します。
  • 音が出ないとき：iPad の音量を上げる。消音モード（ベルに斜線）になっていないか確認。最初の1回はボタンをタップしてから読み上げが始まります（iPad の仕組み上、自動では鳴りません）。
  • こえの種類：「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」で、きれいな声（Kyoko・O-ren など）をダウンロードしておくと聞き取りやすくなります。アプリの設定画面で選べます。
  • 自動ロック：授業中に画面が消えないよう、「設定」→「画面表示と明るさ」→「自動ロック」を長めに。
  • 向き：横向きがおすすめ（ボタンが4列で1画面に収まります）。縦向きでも使えます。

7. ボタン（教科・気持ち）を編集する／写真を使う

スプレッドシートの master シートを編集して、iPad のアプリを開き直すと反映されます（設定画面の「🔄 データを読みこむ」でも反映）。上から順番にボタンが並びます。

列意味書き方の例
id番号（重ならなければ何でもOK。空でも動きます）s01, f01
category教科 か 気持ち（プルダウンで選べます）教科 ／ 気持ち
nameボタンと結果に表示される言葉こくご ／ たのしかった
emoji絵文字（画像がないとき・読みこめないときに表示）
Windows では Win+. で絵文字を入力できます		📖 ／ 😄
imageUrl写真・イラストのURL（空なら絵文字）Googleドライブの共有リンク
yomi読み上げの読み方（空なら name を読む）。漢字の読みまちがい対策にじりつかつどう
colorボタンのわくの色（空なら自動）#FFD43B
showチェックを外すと、そのボタンをかくします☑ ／ ☐
💡 よくある使い方
  • 「きゅうしょく」「そうじ」「あさのかい」など活動も category は「教科」でOKです。
  • 選択肢が多いと迷う児童には、show のチェックを外して 数を減らすと選びやすくなります。
  • 結果の文は設定画面で変えられます（例：「{教科}の じかん、{気持ち}！」）。

写真（Googleドライブ）を使う手順

  1. Google ドライブに画像（JPG / PNG）をアップロードします。
  2. 画像を右クリック → 共有 → 共有。
  3. 「一般的なアクセス」を リンクを知っている全員（閲覧者）に変更 → リンクをコピー。
  4. コピーしたリンク（https://drive.google.com/file/d/…/view?usp=sharing）を、そのまま imageUrl 列に貼ります。表示用のURLへの変換はアプリが自動で行います。
⚠ 写真の注意
  • 児童の顔が写った写真は使わないでください（リンクを知っている人は見られる状態になるため）。教室・教材・給食のイラストなどがおすすめです。
  • 学校のアカウントでは「リンクを知っている全員」が選べないことがあります。その場合は画像が表示されず、自動的に絵文字が表示されます（アプリは止まりません）。
  • 画像はなるべく小さめ（横 1000px 以下）にすると表示が速くなります。

8. 先生用せってい画面の使い方

アプリ右上のうすい ⚙️ を 1.5秒ながおし すると開きます（児童が触ってもすぐには開かないようにしています）。パソコンでは Shift+S でも開けます。設定は その端末だけ に保存されます。

項目内容
GAS の URL ／ データを読みこむ方法Bのときに URL を入力。読みこみ状態（件数・エラー）も表示されます
自動で読み上げる気持ちを選んだら、すぐ結果の文を読み上げます
名前を読み上げるボタンを押したとき、その言葉を読み上げます（文字が読めない児童に）
こえ・はやさ・高さ聞き取りやすく調整できます。「ためしに読む」で確認
ボタンの列の数列を減らすとボタンが大きくなります（手先の操作が難しい児童に）
アニメーションを少なく動きへの刺激に敏感な児童に
結果の文のかたち{教科} {気持ち} が選んだ言葉に入れかわります
記録するオンにすると、スプレッドシートに「log」シートができ、日時・教科・気持ちが記録されます
ℹ 誤タップをふせぐ工夫 画面が切りかわった直後（約0.6秒）のタップは受けつけません。連打しても2つ選ばれることはありません。選んだボタンは大きく強調され、ほかのボタンはうすくなります。
ℹ 通信が切れても大丈夫 一度読みこんだデータは iPad に保存されるので、次に開いたときは通信を待たずにすぐ表示されます（裏で最新データに更新します）。

9. こまったとき

こまったこと確認すること
サンプルのボタンしか出ない設定画面の状態表示を見ます。
・方法B：URL が /exec で終わっているか（/dev は不可）
・デプロイの「アクセスできるユーザー」が「全員」か
・パソコンのブラウザで （URL）?api=data を開き、{"ok":true,…} と表示されるか
?api=data で「シート master が見つかりません」シート名が master（半角小文字）になっているか。3. の setupSampleSheet を実行してください
スプレッドシートを変えたのに反映されないアプリを開き直す、または設定画面の「🔄 データを読みこむ」。それでもだめなら ?api=data で確認
コードを直したのに変わらない「デプロイを管理」→ 編集 →「新バージョン」でデプロイし直す（4. のヒント）
「管理者によってブロックされています」学校の管理者が Apps Script を制限しています。情報担当の先生・管理者に相談するか、個人の Google アカウントで作成してください（その場合も個人情報は入れないでください）
「全員」が選べない学校アカウントの制限です。「（学校名）内の全員」を選び、iPad の Safari で学校アカウントにログインして方法Aで開きます
画像が出ない（絵文字になる）ドライブの共有が「リンクを知っている全員」になっているか。学校アカウントでは制限されることがあります
音が出ない音量・消音モード・Bluetooth スピーカーの接続先を確認。設定画面の「ためしに読む」でテスト
読み方がおかしいスプレッドシートの yomi 列にひらがなで読み方を書きます
ボタンが小さい／多すぎる設定画面で列の数を減らす。show のチェックでボタンの数を減らす

きもちボード ／ 構成：HTML + JavaScript（フロント）＋ Google スプレッドシート + Google Apps Script（データ）
